# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and helpful, assume good intent, and keep discussions focused on the
project. Harassment or personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainer via
[GitHub](https://github.com/dominikamann) or [amannlabs.eu](https://amannlabs.eu).
